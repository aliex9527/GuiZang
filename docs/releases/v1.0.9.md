## 本版改动

- `52220b5` 首次启动先问「创建资料库 / 打开已有资料库」
  - 以前第一次运行会默默在程序目录建个空库，用户既没被告知也不知道笔记存哪
  - 新增 ui/welcome.py：卡片式欢迎框，两个入口（创建 / 打开），关闭即退出；创建时默认落在程序目录（不可写则退回用户数据目录），选到已存在的文件名会提示重选而不是覆盖；打开只接受 .db，选错格式有提示
  - core/ui_state.py：新增 default_library_path()（程序目录可写就便携，否则系统目录）与 is_first_run()（便携库不存在即首次）
  - main.py：无 --db/--data/-d 或 GUIZANG_DB 且属首次时才弹欢迎框；创建失败（路径不可写、文件损坏）提示后可重选，不会半路崩掉
- `54ec4a6` 消息框统一：按钮底色加深 + 整排居中 + 中文按钮
  - 新增 ui/msgbox.py：decorate() 套底色（btn_bg 三档）并用QDialogButtonBox.setCenterButtons(True) 把按钮排到正中间；ask()/info()/warn()/error()…
  - 删除条目、删除附件、新建库覆盖、导入位置、精简数据库等确认框全部换过来，危险操作默认键是「取消」且焦点也在取消上，回车不会误删
  - confirm_unsaved 的私有 QSS 收编到 msgbox，样式只留一份
  - 清掉 database_view / attachments / open_file / main_window 里的静态QMessageBox 调用（那些框既没底色也不受全局样式控制）
  - 修 QMessageBox.about 的版本框：改用统一提示框，按钮位置与其它提示一致

## 使用说明

- 便携版：双击 `GuiZang-1.0.9-windows-x64.exe` 即用，资料库 `归藏.db` 就在 exe 同目录。
- 本目录是**该版本的归档**，里面的 `归藏.db` 是打包时的数据快照；日常使用请以最新版本目录为准。
- 覆盖升级：把旧目录里的 `归藏.db` 复制到新目录即可（或在软件里用「备份 / 恢复」搬运）。
