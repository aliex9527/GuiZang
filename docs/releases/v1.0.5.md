## 本版改动

- `8728c79` 未保存对话框的「保存/不保存/取消」按钮加底色：主题新增 btn_bg/btn_bg_hover/btn_bg_pressed 三档 token，浅色 #d9dfe9、深色 #3a4351，默认按钮描边用 accent_line；版本 1.0.5

## 使用说明

- 便携版：双击 `GuiZang-<版本>-windows-x64.exe` 即用，资料库 `归藏.db` 就在 exe 同目录。
- 本目录是**该版本的归档**，里面的 `归藏.db` 是打包时的数据快照；日常使用请以最新版本目录为准。
- 覆盖升级：把旧目录里的 `归藏.db` 复制到新目录即可（或在软件里用「备份 / 恢复」搬运）。
