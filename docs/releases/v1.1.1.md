## 本版改动

- `1b1017f` 新增 Linux 版：单目录打包 + tar.gz + CI 出包
  - GuiZang_linux.spec：PyInstaller onedir（Linux 上 onefile 每次启动都要解压 Qt，冷启动慢且受 /tmp 限制，单目录更稳）
  - build_linux.sh：本地一键构建，自动建 .venv-linux、检查 Qt 运行库、打 tar.gz
  - .github/workflows/build-linux.yml：ubuntu-22.04 上构建，打 tag 时上传GuiZang-<版本>-linux-x64.tar.gz 到 Release；系统库按 PySide6 的 xcb …
  - tools/linux_readme.txt：随包的使用说明模板（版本号占位，打包时替换）
  - README_linux.md：下载、依赖、自建、数据兼容说明
- `87266e8` 版本 1.1.0：数据库压缩存储

## 使用说明

- 便携版：双击 `GuiZang-1.1.1-windows-x64.exe` 即用，资料库 `归藏.db` 就在 exe 同目录。
- 本目录是**该版本的归档**，里面的 `归藏.db` 是打包时的数据快照；日常使用请以最新版本目录为准。
- 覆盖升级：把旧目录里的 `归藏.db` 复制到新目录即可（或在软件里用「备份 / 恢复」搬运）。
