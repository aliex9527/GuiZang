## 本版改动

- **编辑区换成单栏就地渲染**：写 Markdown 时标记（`#`、`**`、反引号、链接目标）在非光标行缩到 0.1pt 并染成背景色，视觉上消失、文字就地排版；光标所在的块保留排版但显示标记，和 Typora 一致。不再有「左边源码 + 右边预览」的分屏，也不再重建文档——只给字符打格式，光标位置、输入法、撤销栈都不受影响。
- **存盘内容 = 你写的原文**：`toPlainText()` 是唯一真相，保存链路不再做 HTML→Markdown 反序列化，表格、列表里的代码块、`\|`、对齐方式都不会被改写。
- **渲染引擎：自研 `mdengine` 设为默认**（此前需 `GUICANG_MD_ENGINE=1` 才启用）。编辑、预览、导出、反向 HTML→Markdown 全部走自研引擎；设 `GUICANG_MD_ENGINE=0` 可退回第三方 `markdown` / `html2text`。
- 自研引擎能力：ATX / Setext 标题（支持 `{#id}`）、粗体 / 斜体 / 删除线 / `==高亮==`、引用（含嵌套）、有序 / 无序 / 任务列表（Qt 下渲染为 ☐/☑）、表格（含对齐）、围栏 / 缩进代码块（内置多语言高亮：python / js / sql / diff 等）、链接 / 图片 / 引用式链接 / 自动链接 / `gzs://` 内嵌图 / `{width=}`、Admonition、原生 HTML 透传；并提供 HTML→Markdown 反向转换。
- 新增 `python -m mdengine --serve`：本地实时预览服务（纯标准库，只监听 `127.0.0.1`），按块增量渲染，预览跟随光标滚动，Ctrl+S 原地写回。
- **右侧标题导航条归位**：单栏改版后它曾缩在编辑区左上角，现在贴在编辑区右边缘、上下通高；悬停弹出的标题列表贴着导航条展开，且标题先去掉行内 Markdown 标记（`**粗**`、`` `代码` ``、`[文字](地址)` 只显示文字），不再露出源码符号。
- **标题前的 `#` 不再显示**：光标停在标题行时也不再露出井号（以前 Typora 式地显示标记），标题只呈现放大加粗后的文字；井号仍在原文里，切源码模式或用工具栏改级别都不受影响。
- **所有 Markdown 标记一律隐藏**：`**`、`*`、反引号、`~~`、`==`、`[](地址)`、`>`、`---`、` ``` `、表格分隔行在编辑区全部不可见，光标停在哪一段都一样——编辑区看上去就是排版结果。无序列表的 `-` 换成由装饰层绘制的圆点（嵌套层级照样缩进），有序编号保留（成品渲染也显示数字），代码块只留语言名标签。要看原文随时切「源码模式」。
- **深色主题补齐系统边角**：以前切深色只换了 QSS，窗口顶上的系统标题栏和资料库标签栏（`归藏.db` 那一条）仍是白的。现在连 QPalette 一起换，标签栏、滚动条槽、对话框按钮区都跟着走；系统标题栏改用 DWM 的沉浸式深色属性（Win10 呈纯黑、Win11 还能跟随面板色），任何对话框一打开就自动套用，切回浅色也立即恢复。
- **空行按 Ctrl+1 后打字不再是标题的问题修掉了**：`# ` 插进去之后光标曾被放回第 0 列（停在井号**前面**），接着打的字落在标记之前，整行变成「标题# 」，而井号又被渲染层藏起来，看上去就像快捷键没生效。现在整行重写统一按"光标右边还剩几个字符"换算光标位置，并至少留出前缀长度——空行按 Ctrl+1 光标落在 `# ` 之后，打字立刻是标题；标题改级别、去掉标题、加列表、加引用时光标也留在原来的字缝里（以前会跳到行尾）。
- 测试：134 项（含 `test_mdengine` / `test_bridge` / `test_live` / `test_live_render`）全部通过。

## 使用说明

- 便携版：双击 `GuiZang-1.1.4-windows-x64.exe` 即用，资料库 `归藏.db` 就在 exe 同目录。
- 本目录是**该版本的归档**，里面的 `归藏.db` 是打包时的数据快照；日常使用请以最新版本目录为准。
- 覆盖升级：把旧目录里的 `归藏.db` 复制到新目录即可（或在软件里用「备份 / 恢复」搬运）。
