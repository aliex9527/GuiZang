## 本版改动

- `314f1af` 编辑界面默认不显示附件栏
  - 附件栏默认收起：只留正文，需要时从「视图 → 显示附件栏」或 Ctrl+Shift+E 叫出来
  - 旧库迁移：旧版默认展开，库里已经存了 attach_panel=true，用一次性标记attach_panel_migrated 把这个旧值作废一次；之后用户手动开关会照常记住
  - 修 _select_node 里只 setVisible(True) 不隐藏的问题：那是附件栏「怎么关都关不掉」的真正原因，一旦被别的路径显示过，切条目就再也收不起来；改为按开关状态显式设置
  - keymap 新增 attach_panel 动作（视图 / Ctrl+Shift+E），菜单项也带上按键提示
- `57e0872` 版本说明补全：改动清单带上提交正文里的要点（折行自动拼接），八份说明按新格式重生成

## 使用说明

- 便携版：双击 `GuiZang-1.0.8-windows-x64.exe` 即用，资料库 `归藏.db` 就在 exe 同目录。
- 本目录是**该版本的归档**，里面的 `归藏.db` 是打包时的数据快照；日常使用请以最新版本目录为准。
- 覆盖升级：把旧目录里的 `归藏.db` 复制到新目录即可（或在软件里用「备份 / 恢复」搬运）。
