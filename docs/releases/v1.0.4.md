## 本版改动

- `dbd3404` 版本号统一为 1.0.4 并写入 exe：新增 VERSION 单一来源 + tools/win_version.py 生成版本资源（右键属性可见 文件/产品版本）；新增 tools/build_win.py，每个版本输出到 dist/GuiZang-<版本>-windows-x64/，已存在则拒绝覆盖，支持 --bump/--minor/--major/--set；mac spec 与两个 CI 工作流改为读 VERSION；关于对话框显示版本
- `55d0493` 改为完全手动保存：去掉正文/标题的自动落盘，只在 Ctrl+S 或用户确认时写库；切换条目、关闭标签、关闭窗口时弹「保存/不保存/取消」三选一，取消则留在原地；修关标签时先关库再摘标签导致状态栏查已关闭数据库崩溃
- `d0ad571` 修复标题快捷键与保存策略：块基准字符格式随标题立即生效（光标/后续输入都变字号）；修 KeyPress 兜底通道 int(modifiers) 在 PySide6 6.12 抛 TypeError（顺带同键双触发去重）；去掉正文实时保存，改为 Ctrl+S / 切换条目 / 关闭时落盘并在标题栏提示未保存
- `5a41ae1` 导航条预览卡片改为内容自适应：宽度贴合最长标题（120~340px，按像素截断）、高度按真实行高动态开窗；行字号随标题级别递减 H1 14px→H6 10px，层级缩进，整体更紧凑
- `d05b148` 导航条：刻度改固定 12px 紧凑间距（垂直居中，不再拉伸留空隙）；悬停预览改为整列标题列表，当前行加粗高亮，超高按当前项开窗并受编辑区高度约束
- `9696b38` 导航条：悬停刻度弹出详情预览卡片（级别徽标+标题全文+正文摘要+本节段落数/字数）
- `b69023a` 新增：编辑器右侧标题导航条（仿消息导航刻度）——每个标题一条刻度，点击跳转，滚动实时指示当前位置
- `1a97688` 新增：导入 Markdown 文件入库 + 全部快捷键自定义设置（数据驱动键表，改键持久化进库，F1 一览与菜单实时同步）
- `8c6df8b` 修复 Release 发布权限：workflow 加 contents: write
- `62e6e49` 图标入库，CI 不再运行时用 Qt 渲染（修复 Windows runner 无头环境图标生成失败）
- `b74ec9d` 新增 Windows 打包工作流：版本号与 macOS 版同源，打 tag 自动出 exe 并发 Release
- `026e193` 加入一键环境脚本：新机器上装完 Python 就能跑

## 使用说明

- 便携版：双击 `GuiZang-<版本>-windows-x64.exe` 即用，资料库 `归藏.db` 就在 exe 同目录。
- 本目录是**该版本的归档**，里面的 `归藏.db` 是打包时的数据快照；日常使用请以最新版本目录为准。
- 覆盖升级：把旧目录里的 `归藏.db` 复制到新目录即可（或在软件里用「备份 / 恢复」搬运）。
