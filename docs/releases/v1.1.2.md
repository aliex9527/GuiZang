## 本版改动

- `ad2ad55` 修 read_version 不接受字符串路径：PyInstaller 注入的 SPECPATH 是 str
  - 在 root 为 str 时抛TypeError: unsupported operand type(s) for /: 'str' and 'str'
  - 直接跑 pyinstaller GuiZang.spec（不带 GZ_VERSION 环境变量）必崩，CI 的 Windows 构建就是这样挂的
  - 统一用 Path(root or root_dir()) 兜住 str / Path 两种输入
- `0ed00f4` 版本 1.1.1：新增 Linux 版（Windows / macOS / Linux 三平台）

## 使用说明

- 便携版：双击 `GuiZang-1.1.2-windows-x64.exe` 即用，资料库 `归藏.db` 就在 exe 同目录。
- 本目录是**该版本的归档**，里面的 `归藏.db` 是打包时的数据快照；日常使用请以最新版本目录为准。
- 覆盖升级：把旧目录里的 `归藏.db` 复制到新目录即可（或在软件里用「备份 / 恢复」搬运）。
